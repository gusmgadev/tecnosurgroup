# public/images/clientes/

Logos de clientes y empresas que trabajan con Tecnosur Group.

## Convención de nombres
- `cliente-nombre-empresa.png` (kebab-case, sin espacios ni mayúsculas)

## Recomendaciones
- Alto máximo: 60px (se muestran en fila en la sección de clientes)
- Formato: PNG con fondo transparente
- Ancho variable — se adaptan con `object-contain`
