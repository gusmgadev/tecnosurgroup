# public/images/logos/

Logos de la marca Tecnosur Group.

## Archivos esperados
- `logo.png` — Logo principal (sobre fondos claros)
- `logo-white.png` — Logo blanco (sobre fondos oscuros como el navbar)

## Tamaños configurados en theme.ts
- Ancho: `theme.logo.width` → 160px
- Alto: `theme.logo.height` → 40px

## Rutas en theme.ts
- `theme.logo.path` → `/images/logos/logo.png`
- `theme.logo.pathWhite` → `/images/logos/logo-white.png`
