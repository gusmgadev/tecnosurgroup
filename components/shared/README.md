# components/shared/

Componentes reutilizables en cualquier zona del proyecto.

## Qué va acá
- `button.tsx` — Botón base del sistema de diseño
- `input.tsx` — Input base con validación
- `modal.tsx` — Modal reutilizable
- `spinner.tsx` — Indicador de carga
- `error-message.tsx` — Mensaje de error estandarizado

## Reglas
- Sin dependencia de ninguna zona específica (ni landing ni dashboard)
- Sin lógica de negocio — solo UI pura y reutilizable
- Importables desde cualquier parte del proyecto
